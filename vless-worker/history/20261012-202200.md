# Implementation summary

Added per-connection WebSocket lifecycle, bounded serialized upload queues, handshake and upstream I/O deadlines, direct TCP routing and optional SOCKS5 routing with RFC 1929 authentication. SOCKS5 replies are read incrementally, and target bytes coalesced with the CONNECT reply are preserved. DNS-only UDP uses bounded DNS-over-HTTPS requests and incremental length framing. Proxy failures close the connection without silently falling back to direct routing. Transport tests passed.

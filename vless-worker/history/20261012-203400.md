# Implementation summary

Added explicit raw TCP relay selection through PROXYIP. SOCKS5 takes precedence when both are configured. An explicit relay port overrides the requested port; otherwise the requested port is retained. Payload remains unchanged. This is configured routing, not automatic direct-to-relay replay or a general CONNECT proxy. Routing and validation tests passed.
